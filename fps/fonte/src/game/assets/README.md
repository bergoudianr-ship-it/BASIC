# Assets CC0

Copiados de `@pmndrs/assets@1.7.0` (npm, licença CC0-1.0, ver `LICENSE-pmndrs-assets.txt`).
São módulos que exportam um data URI (base64), então o jogo continua num arquivo só e funciona offline.

- `hdri-sunset.ts`, `hdri-sky.ts`, `hdri-city.ts`: HDRIs (origem Poly Haven), usados só como luz de ambiente (IBL).
- `normal-00xx.ts`: normal maps sem emenda, aplicados em triplanar nas superfícies (ver `graphics.ts`).
